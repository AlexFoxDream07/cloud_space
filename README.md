#CloudFlow Platform

Данный проект предназначен для первой попытки создания облачного веб-приложения.

Используемые технологии: express

Для того чтобы начат проект нужно в терминале прописать данные команды: npm install(установит все необходимый зависимости), npm start(для запуска самого сервера).

HTTP-маршруты:
app.get("/api/status") - получение статуса
app.get("/api/services") - получение сервисов
app.get("/api/services/:id") - получение конкретного сервиса
app.post("/api/services") - ответ на полученный статус
app.get("/api/hello") - получение приветствия
